Home System Extension Board Template

This KiCad template provides a ready-to-use extension board layout with all essential connectors already placed.

Board size: 130 mm × 85 mm

Features

  • Predefined power rails (5V and 3.3V)
  • GPIO expansion connectors
  • I²C interface support
  • Reserved space for additional sensors and modules
  • Prepared PCB design rules
  • Optimized starting layout for home automation projects

Template Information

Author Wojciech Zarzycki
Version v1.0
Compatible With KiCad 8+
Template Type Extension Board / Home Automation

Notes

The template is intended as a quick starting point for creating custom home system extension boards. You can freely modify connectors, dimensions, and routing rules according to your project needs.
